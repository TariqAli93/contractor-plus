# Workflow

## Workflow الرئيسي

1. إضافة عميل
2. إنشاء عقد
3. اختيار قالب بناء
4. إدخال المساحة والطوابق
5. النظام يولد:
   - مواد
   - كلفة
   - مراحل
   - مدة تنفيذ
   - ربح متوقع
6. تعديل يدوي إذا لزم
7. اعتماد العقد
8. إنشاء مشروع
9. تسجيل المصاريف
10. تسجيل الدفعات
11. متابعة التنفيذ
12. عرض الربح والخسارة

---

## Workflow العلاقات

Customer

→ Template
→ Project
→ Costs + Payments + Progress
→ Profit & Loss
