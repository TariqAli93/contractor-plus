# Vision

## الهدف من النظام

بناء برنامج مقاولات بسيط وعملي
يركز على:

Project Profitability

أي:

- شكد اتفقت ويه العميل؟
- شكد صرفت فعلياً؟
- شكد استلمت دفعات؟
- شكد ربحت أو خسرت؟

النظام لا يركز فقط على:

- المواد
- المخازن
- التندرات

بل يركز على:
تحويل العقد إلى مشروع مربح يمكن تتبع ربحيته لحظياً.

---

## الفكرة الأساسية

كل شيء داخل النظام يدور حول:

Project / موقع البناء

العقد يولد مشروع
القالب يولد مواد
المصاريف تولد ربح وخسارة
المراحل تولد نسبة إنجاز

---

## أهداف النظام

- تقليل الإدخال اليدوي
- منع تكرار البيانات
- معرفة الربح الحقيقي لكل مشروع
- تسهيل متابعة المشاريع
- معرفة الدفعات المتأخرة
- متابعة نسب الإنجاز
- الوصول الخارجي عبر Cloudflare Tunnel

---

## الفئة المستهدفة

- المقاولين
- شركات البناء الصغيرة والمتوسطة
- مهندسي التنفيذ
- المحاسبين
