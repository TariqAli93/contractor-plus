# Design Context

The UI lives in `frontend/` (Vue 3 + Vuetify 3 + Tailwind, Electron desktop shell, Arabic/RTL).

- **Register:** `product` — design serves the task (see `frontend/PRODUCT.md`).
- **Platform:** `web` — Electron renders the SPA as HTML/CSS. Intended design *language* is native-desktop business software (dense, hairline-bordered, low-radius), not a roomy web dashboard.
- **Strategic brief:** `frontend/PRODUCT.md` (users, purpose, brand personality, anti-references, design principles).
- **Visual system:** `frontend/DESIGN.md` (colors, typography, elevation, components) once generated.

When designing or reshaping UI, read `frontend/PRODUCT.md` (and `frontend/DESIGN.md`) first so work stays on-brand.
